ডাউনলোড

বিনামূল্যে, কোনো নিবন্ধন ছাড়া। আপনার ডিভাইসের সংস্করণ সবার আগে দেখানো হলো — অন্যগুলোও নামাতে পারবেন।

আপনার ডিভাইস:

Windows

Windows 10 ও 11 (৬৪-বিট) · ২.৮ MB

  1. ইনস্টলার চালান।
  2. Win+Space দিয়ে “জুলাই বাংলা কীবোর্ড” বেছে নিন।
  3. Ctrl+Alt+B দিয়ে মোড বদলান।
Windows-এর জন্য ডাউনলোড

Android

Android ৭ বা নতুন · ০.৬ MB · কোনো অনুমতি লাগে না

  1. APK নামিয়ে ইনস্টল করুন।
  2. অ্যাপ খুলে “কীবোর্ড চালু করুন” ও “বেছে নিন” চাপুন।
  3. মোড বোতাম (বাং / ক্লা / EN) দিয়ে মোড বদলান।
Android-এর জন্য ডাউনলোড

Linux

Ubuntu ২৪.০৪ বা নতুন, Debian ১৩ (৬৪-বিট) · IBus · ০.২ MB

  1. ফাইলটি নামিয়ে দুবার ক্লিক করে ইনস্টল করুন, অথবা টার্মিনালে: sudo apt install ./JulyBanglaKeyboard-linux-amd64.deb (বাংলা ফন্টও সাথে আসে)।
  2. একবার Log out করে আবার Log in করুন।
  3. Settings → Keyboard → Input Sources → + → Bangla → “July Bangla Keyboard”। Ctrl+Alt+B দিয়ে মোড বদলান।
Linux-এর জন্য ডাউনলোড

এটি প্রিভিউ সংস্করণ; ডিজিটাল স্বাক্ষর এখনো নেই, তাই Windows “অজানা প্রকাশক” দেখাতে পারে। শুধু এই সাইট বা GitHub রিলিজ থেকে নামান। macOS ও iPhone সংস্করণ পরিকল্পনায় আছে।
