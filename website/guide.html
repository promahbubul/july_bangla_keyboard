ব্যবহার নির্দেশিকা

শুরু করা, মোড, লেখার নিয়ম আর সাধারণ সমস্যার সমাধান — এক জায়গায়।

শুরু করা মোড লেখার নিয়ম সমস্যা ও সমাধান প্রশ্নোত্তর

শুরু করা

Windows

  1. ইনস্টলার চালান। “জুলাই বাংলা কীবোর্ড” ভাষার তালিকায় যোগ হবে।
  2. Win+Space চেপে কীবোর্ডটি বেছে নিন।
  3. Ctrl+Alt+B চেপে বাংলা মোডে যান। স্ক্রিনের উপরের ছোট বার আর ট্রে-আইকন মোড দেখায়।

Linux (Ubuntu, Debian)

  1. .deb ফাইল ইনস্টল করুন। বাংলা ফন্টও সাথে ইনস্টল হয়।
  2. একবার Log out করে আবার Log in করুন।
  3. Settings → Keyboard → Input Sources → + → Bangla → “July Bangla Keyboard” যোগ করুন, Super+Space দিয়ে বেছে নিন, Ctrl+Alt+B দিয়ে মোড বদলান।

Android

  1. অ্যাপ ইনস্টল করে খুলুন।
  2. “১. কীবোর্ড চালু করুন” — তালিকায় জুলাই বাংলা চালু করুন।
  3. “২. জুলাই বাংলা বেছে নিন” — তারপর যেকোনো লেখার ঘরে লিখুন।

সমস্যা ও সমাধান

নতুন সংস্করণ ইনস্টলের পরেও পুরনো আচরণ

আগে থেকে খোলা প্রোগ্রাম পুরনো সংস্করণ ধরে রাখে। একবার Sign out করে আবার Sign in করুন, অথবা কম্পিউটার রিস্টার্ট দিন।

Win+Space-এ কীবোর্ডটি নেই

Settings → Time & language → Language & region → বাংলা (বাংলাদেশ) → ⋯ → Language options → Add a keyboard থেকে “July Bangla Keyboard” যোগ করুন।

Ctrl+Alt+B কাজ করছে না

আগে Win+Space দিয়ে জুলাই বাংলা কীবোর্ড বেছে নিন। কোনো প্রোগ্রাম নিজেই এই শর্টকাট ব্যবহার করলে ট্রে-আইকন বা মোড-বারে ক্লিক করে মোড বদলান।

ক্লাসিক মোডে ইংরেজি অক্ষরের মতো লেখা আসে

এটাই স্বাভাবিক — লেখাটি বেছে নিয়ে ফন্ট SutonnyMJ করুন। ট্রে-মেনুর “Classic ডায়াগনস্টিক” দেখাবে ফন্ট ইনস্টল আছে কিনা।

মোড-বার বা ট্রে-আইকন দেখা যাচ্ছে না

Start মেনু থেকে July Bangla Keyboard খুলুন। ট্রে-মেনুতে “Windows চালু হলে চালু” টিক দিলে প্রতিবার নিজে থেকে আসবে। প্রোগ্রামটি “Run as administrator” দিয়ে খুলবেন না।

কিছু গেম বা নিরাপত্তা-সফটওয়্যারে কাজ করে না

কিছু গেম ও anti-cheat সফটওয়্যার বাইরের কীবোর্ড-সার্ভিস ঢুকতে দেয় না। এটা ইচ্ছাকৃত সুরক্ষা; আমরা তা এড়ানোর চেষ্টা করি না।

সমাধান না পেলে GitHub-এ সমস্যা জানান — কোন অ্যাপে, কোন কী চেপে কী এসেছে, লিখে দিন।

প্রশ্নোত্তর

এটা কি সত্যিই বিনামূল্যে?

হ্যাঁ। কোনো টাকা, নিবন্ধন বা বিজ্ঞাপন নেই। সব কোড GitHub-এ খোলা।

আগে বিজয় ব্যবহার করতাম — নতুন করে শিখতে হবে?

না। কী-বিন্যাস আর লেখার নিয়ম বিজয়ের মতোই। জুলাই বাংলা কীবোর্ড একটি স্বাধীন প্রকল্প, যা বিজয়-সামঞ্জস্যপূর্ণ লেআউট ব্যবহার করে।

আমার লেখা কি কোথাও পাঠানো হয়?

না। কীবোর্ড ইন্টারনেট ব্যবহার করে না, লেখা জমা রাখে না। বিস্তারিত গোপনীয়তা নীতিতে।

কোন কোন অ্যাপে কাজ করে?

Windows-এর নিজস্ব ইনপুট ব্যবস্থায় (TSF) তৈরি, তাই Word, Notepad, Chrome, Edge, Facebook-সহ সাধারণ অ্যাপে কাজ করে। Android-এ যেকোনো লেখার ঘরে।

Windows “অজানা প্রকাশক” দেখাচ্ছে কেন?

প্রিভিউ সংস্করণে এখনো ডিজিটাল স্বাক্ষর নেই; চূড়ান্ত সংস্করণে থাকবে। শুধু এই সাইট বা GitHub থেকেই নামান।

macOS বা iPhone সংস্করণ কবে?

Windows, Android ও Linux সংস্করণ এখন পাওয়া যাচ্ছে; macOS ও iPhone পরিকল্পনায় আছে। সব সংস্করণ একই কীবোর্ড-ইঞ্জিন ব্যবহার করে, তাই একই কী-তে একই লেখা আসে।
