# Website

The project website: static pages, with no build step, no tracking and no third-party
requests. The fonts are self-hosted. Open `index.html` in a browser to preview it.

| Page | Contents |
|---|---|
| `index.html` | Hero with a download button for the visitor's device, typing demo, features, the Bijoy layout, the remembrance section |
| `download.html` | Every platform; the visitor's device is shown first and marked |
| `guide.html` | Getting started, modes, typing rules, troubleshooting, FAQ |
| `about.html` | The name, principles, how to contribute, contact |
| `privacy.html`, `terms.html` | Privacy policy, terms of use, license, trademarks, credits |
| `code-signing.html` | Code signing policy: build, team roles, privacy |
| `404.html` | Not-found page |

Notes:

- **Shared header and footer.** Every page repeats the same header and footer. Change all
  of them together.
- **Download links** point to
  `releases/latest/download/JulyBanglaKeyboard-Setup.exe` and `JulyBanglaKeyboard.apk`.
  Every release must attach files with exactly these names.
- **Device detection** runs only in the browser (`assets/site.js`). Nothing is stored or
  sent.
- **Generated files.**
  - `assets/layout.js` is generated from `layouts/bijoy.layout` by
    `tools/Make-WebsiteLayout.ps1`.
  - `logo.png`, `favicon.png` and `july36.jpg` are generated by `tools/Make-Icons.ps1`.
- **Publishing.** The site is live at <https://julykeyboard.vercel.app/>. Vercel publishes
  this folder when `main` changes. It is the only official website.
